# MonoLab Homebrew Tap (retired)

The MonoLab apps are no longer distributed through Homebrew.

- **Get the apps:** [monolabapps.gumroad.com](https://monolabapps.gumroad.com)
- **Source code (MIT):** [CleanKeys](https://github.com/alaska14/cleankeys) · [FoldAwake](https://github.com/alaska14/foldawake) · [ChargeWatts](https://github.com/alaska14/chargewatts) · [BrightKeys](https://github.com/alaska14/brightkeys). Each repo has a `build.sh` to build the app yourself.

If you installed an app through this tap before, quit it and remove it with `brew uninstall --cask <name>` before untapping.
