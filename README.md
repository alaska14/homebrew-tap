# MonoLab macOS Utilities

Official Homebrew Tap for **MonoLab** native macOS software.

## Setup

```bash
brew tap alaska14/tap
brew trust alaska14/tap   # required by Homebrew 7+ for third-party taps
```

## Applications

- **CleanKeys:** Distraction-free volume & brightness on macOS. Fully headless.  
  👉 [Get on Gumroad ($2.99+)](https://monolabapps.gumroad.com/l/cleankeys) · [GitHub Repo](https://github.com/alaska14/cleankeys)
  ```bash
  brew install --cask alaska14/tap/cleankeys
  ```

- **FoldAwake:** Run your MacBook with the lid closed without external displays or overheating.  
  👉 [Get on Gumroad ($2.99+)](https://monolabapps.gumroad.com/l/foldawake) · [GitHub Repo](https://github.com/alaska14/foldawake)
  ```bash
  brew install --cask alaska14/tap/foldawake
  ```

- **ChargeWatts:** 1:1 pixel-perfect Apple battery replacement that shows live wattage on hover & plug-in.  
  👉 [Get on Gumroad ($2.99+)](https://monolabapps.gumroad.com/l/chargewatts) · [GitHub Repo](https://github.com/alaska14/chargewatts)
  ```bash
  brew install --cask alaska14/tap/chargewatts
  ```

- **BrightKeys:** Restore F5/F6 keyboard backlight control on Apple Silicon MacBooks.  
  👉 [GitHub Repo](https://github.com/alaska14/brightkeys)
  ```bash
  brew install --cask alaska14/tap/brightkeys
  ```

> The apps are not notarized yet: on first launch, right-click the app → **Open** (or System Settings → Privacy & Security → **Open Anyway**).
