# homebrew-tap

Official Homebrew Cask tap for **Modo Labs** macOS utilities.

## How to install

```bash
brew tap alaska14/tap
```

### Install CleanKeys (Free):
```bash
brew install --cask cleankeys
```

### Install FoldAwake (Free):
```bash
brew install --cask foldawake
```
